# AGENTS.md

Перед любыми изменениями в этом репозитории прочитайте
[`PROJECT_RULES.md`](PROJECT_RULES.md) — это единый источник правил.

Кратко, самое критичное:

- Прямой push в `main` запрещён. Только pull request.
- Менять `generator/`, затем пересобирать. Сгенерированные HTML руками не
  править.
- Формула не меняется без первоисточника, редакции и эталонного теста.
- Нормативный вердикт запрещён при недостаточных исходных данных.
- Перед PR: `npm ci`, `npm test`, `python3 generator/build.py`,
  `git diff --exit-code`, `npx playwright test`, `npm audit`.
- Новые калькуляторы не добавлять, пока не закрыты P0 и P1 из аудита.

Полный список с пояснениями — в `PROJECT_RULES.md`.
