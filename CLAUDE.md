# CLAUDE.md

Перед любыми изменениями в этом репозитории прочитайте
[`PROJECT_RULES.md`](PROJECT_RULES.md) — это единый источник правил.
Настоящий файл лишь адаптер и ничего не дублирует по существу.

## Что это за проект

Статический сайт инженерных калькуляторов по электрике. Каждая страница
самодостаточна: стили и скрипт внутри HTML, внешних зависимостей во время
работы нет. Публикуется на GitHub Pages из ветки `main`.

## Устройство

- `generator/` — источник правды. `build.py` собирает сайт из `data_*.py`
  по шаблонам в `common.py`.
- `*.html` в корне — **сгенерированный вывод**. Руками не редактировать.
- `tests/verify.mjs` — структурные и функциональные проверки на jsdom.
- `tests/e2e/` — браузерные проверки на Playwright.
- `ENGINEERING_AUDIT.md` — реестр статусов инженерной проверки расчётов.

## Рабочий цикл

```bash
git fetch origin && git checkout -b <ветка> origin/main
# правки в generator/
python3 generator/build.py
git diff --exit-code   # должен пройти после коммита сгенерированного
npm ci && npm test
npx playwright test
```

## Чего делать нельзя

- Push напрямую в `main`.
- Править сгенерированные HTML вместо источника в `generator/`.
- Менять инженерную формулу без ссылки на первоисточник и эталонного теста.
- Выдавать категоричный нормативный вердикт при недостаточных данных.
- Считать «тысячи проверок, 0 ошибок» доказательством корректности формул:
  большая их часть структурная. В отчёте давать разбивку
  structural / functional / boundary / browser.

Остальное — в `PROJECT_RULES.md`.
