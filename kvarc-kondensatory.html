Конденсаторы кварцевого резонатора

Кварц генерирует паспортную частоту, только если видит паспортную нагрузочную ёмкость CL. Калькулятор подбирает конденсаторы под неё, оценивает уход частоты при несовпадении и проверяет запас генератора по усилению по методике ST AN2867. Последовательное соединение конденсаторов само по себе считает калькулятор соединения конденсаторов, а что делать с частотой дальше — делитель частоты и таймер.

Конденсаторы кварца: как считается

CL = C1·C2/(C1 + C2) + Cs;  подбор: C1 = C2 = 2·(CL − Cs)
Нагрузочный резонанс: f = fs·√(1 + C1m/(C0 + CL)),  fs = 1/(2π√(Lm·C1m))
Уход частоты: Δf/f = √((1 + C1m/(C0 + CLсх)) / (1 + C1m/(C0 + CL))) − 1 ≈ C1m·(CL − CLсх) / (2·(C0 + CLсх)·(C0 + CL))
gmcrit = ω²·C1·C2·Rn,  Rn = 2·ESR·S² / (X0² + √(X0⁴ − 4·ESR²·S²)),  S = X + X0,  X = (C1 + C2)/(ω·C1·C2),  X0 = 1/(ω·(C0 + Cs))
При малом ESR: gmcrit ≈ ESR·ω²·(C0 + CL)²·(C1 + C2)²/(C1·C2), при C1 = C2 — 4·ESR·(2πF)²·(C0 + CL)² (ST AN2867);  gm/gmcrit ≥ 5
DL = ESR·IQ²,  IQ = 2πF·Ctot·Vpp/(2√2),  Ctot = C1 + Cs/2 + Cщупа

Нагрузочная ёмкость. В генераторе Пирса микроконтроллера кварц стоит между выводами OSC_IN и OSC_OUT, а от каждого вывода на землю — конденсатор. Кварц видит их последовательно, плюс паразитную ёмкость выводов и дорожек: CL = C1·C2/(C1 + C2) + Cs — так её записывает ST в AN2867. Изготовитель кварца настраивает частоту при паспортной CL, поэтому конденсаторы подбирают под неё: при C1 = C2 = C последовательное соединение равно C/2, откуда C = 2·(CL − Cs), как в AN2867. Cs — сумма ёмкостей выводов и платы, которую видит кварц; ECS Inc. при отсутствии данных предлагает принимать около 5 пФ. Ёмкость вывода на землю добавляется к конденсатору у этого вывода, поэтому в Cs она входит не целиком: при двух выводах по a пФ и C1 = C2 = C получается (C + a)/2 = C/2 + a/2. Точнее всего Cs находят по измеренной частоте.

Почему частота зависит от CL. AN2867 описывает кварц эквивалентной схемой: последовательные Rm, Lm и динамическая ёмкость C1m (Cm) и параллельная им C0 — ёмкость электродов и корпуса. В генераторе кварц вместе с CL образует резонансный контур: реактивное сопротивление кварца равно 1/(ωCL). Если пренебречь Rm, сопротивление кварца — Xm/(1 − ωC0·Xm), где Xm = ωLm − 1/(ωC1m). Приравниваем его к 1/(ωCL): ω·Xm·(C0 + CL) = 1, откуда ω²·Lm = 1/C1m + 1/(C0 + CL) и f = fs·√(1 + C1m/(C0 + CL)). Эта формула воспроизводит пример AN2867: кварц 8 МГц с Rm = 8 Ом, Lm = 14,7 мГн, Cm = 0,027 пФ и C0 = 5,57 пФ даёт fs ≈ 7 988 764 Гц, антирезонанс 8 008 102 Гц и ровно 8 МГц при CL = 4,02 пФ. Отношение частот при фактической и паспортной CL и есть уход частоты; при малом C1m он близок к C1m·(CL − CLсх)/(2·(C0 + CLсх)·(C0 + CL)) — так его записывает Abracon, там же чувствительность 10⁶·C1m/(2·(C0 + CL)²) ppm на пикофарад. Больше CL — ниже частота.

Запас по усилению. Генератор запускается, если крутизна gm его усилителя больше критической — той, при которой отрицательное сопротивление усилителя с конденсаторами только компенсирует потери кварца. AN2867 считает её как gmcrit = 4·ESR·(2πF)²·(C0 + CL)² и рекомендует запас gm/gmcrit не меньше 5: при меньшем генерация может запуститься, но надёжный запуск не гарантирован. В новых паспортах STM32 вместо gm дают Gm_crit_max = gm/5 — тогда gmcrit кварца должна быть меньше неё. Откуда эта формула и где её границы, видно из уравнения генератора с тремя реактивными элементами (правила Кирхгофа для узлов OSC_IN и OSC_OUT): gm·Z1·Z2 + Z1 + Z2 + Z3 = 0, где Z1 = 1/(jωC1), Z2 = 1/(jωC2), Z3 — кварц. Отсюда Z3 = Rn + jX: усилитель с конденсаторами для кварца — отрицательное сопротивление −Rn, Rn = gm/(ω²·C1·C2), последовательно с ёмкостью C1·C2/(C1 + C2), X = 1/(ω·C1·C2/(C1 + C2)). Параллельно динамической ветви кварца стоит C0 вместе с паразитной Cs, X0 = 1/(ω·(C0 + Cs)); пересчёт через неё даёт для ветви активное сопротивление Rn·X0²/(Rn² + (X + X0)²). Генерация начинается, когда оно равно ESR, — это квадратное уравнение относительно Rn, его меньший корень — в рамке. У уравнения есть и больший корень: при крутизне выше него отрицательное сопротивление, пересчитанное через C0, снова меньше ESR — у обычных микроконтроллеров крутизна намного ниже, но калькулятор проверяет и это. Решения нет вовсе, если ESR больше X0²/(2·(X + X0)): тогда в этой модели генератор не запустится при любой крутизне. Ограниченность отрицательного сопротивления генератора Пирса и связь критической крутизны с C0 разбирают Vittoz и соавторы (IEEE JSSC, 1988). Если ESR мал и Rn² в знаменателе можно отбросить, получается gmcrit ≈ ESR·ω²·(C0 + CL)²·(C1 + C2)²/(C1·C2) — при C1 = C2 это в точности формула AN2867, а при разных конденсаторах значение больше. Точное значение всегда не меньше приближённого; при обычных кварцах разница — около процента, при большом ESR, большой C0 и высокой частоте — заметно больше, поэтому калькулятор показывает оба и считает запас по точному. Наибольший ESR и наименьшая gm из паспортов дают наихудший случай; при заданном допуске конденсаторов gmcrit ищется наибольшая по сетке всей области допуска.

Уровень возбуждения. Мощность, рассеиваемая в кварце, DL = ESR·IQ², не должна превышать паспортную, иначе кварц может разрушиться (AN2867). Ток IQ измеряют токовым пробником или вычисляют по размаху на входе генератора: ток кварца втекает в ёмкость узла OSC_IN, а это C1, половина паразитной ёмкости и ёмкость щупа — Ctot = C1 + Cs/2 + Cщупа по AN2867. Для синуса действующее напряжение Vpp/(2√2), поэтому IQ = 2πF·Ctot·Vpp/(2√2). С наибольшим ESR это оценка сверху. Если DL больше допустимого, AN2867 ставит резистор RExt на выходе генератора.

Чем отличается от соседних страниц. Резонансная частота LC-контура — та же формула 1/(2π√(LC)), что у последовательной ветви кварца, но у кварца добротность в тысячи раз выше. Последовательное соединение C1 и C2 в общем виде считает калькулятор соединения конденсаторов. Как погрешность кварца в ppm переходит в частоту таймера, UART или ШИМ, показывает калькулятор делителя частоты.

Конденсаторы кварца: пример расчёта

Кварц 8 МГц с паспортной CL = 18 пФ, паразитная ёмкость 5 пФ. Нужно C1 = C2 = 2·(18 − 5) = 26 пФ; ближайший номинал E12 — 27 пФ, и CL в схеме 27/2 + 5 = 18,5 пФ — на 0,5 пФ больше паспортной. Если в паспорте кварца C0 = 7 пФ и C1m = 20 фФ (значения условные — берите из паспорта своего кварца), частота уйдёт на −7,837 ppm, то есть на 62,7 Гц вниз; чувствительность — около −15,4 ppm на пикофарад, поэтому ошибка в оценке Cs на 2 пФ даёт уже около 31 ppm.

При ESR кварца не больше 80 Ом (условно) критическая крутизна 4·80·(2π·8 МГц)²·(25,5 пФ)² = 525,7 мкА/В. У STM32F103 gm = 25 мА/В — запас 47,55, больше 5 по AN2867. Если поставить C1 = 22 и C2 = 33 пФ, CL в схеме 18,2 пФ, а критическая крутизна вырастет в (22 + 33)²/(4·22·33) = 1,042 раза.

Частые вопросы

Почему не поставить просто два конденсатора по CL?

Кварц видит конденсаторы последовательно — вдвое меньшую ёмкость, — плюс паразитную ёмкость выводов и дорожек. Поэтому каждый берут около 2·(CL − Cs): для CL = 18 пФ и Cs = 5 пФ это 26 пФ, а не 18.

Что будет, если ёмкость не совпадёт с паспортной?

Кварц всё равно будет генерировать, но на другой частоте: больше CL — ниже частота. Уход зависит от динамической ёмкости C1m и C0 кварца и обычно составляет единицы–десятки ppm на пикофарад. Для часов и интерфейсов это может быть заметно, поэтому частоту проверяют измерением.

Что означает запас по усилению 5?

Это рекомендация ST в AN2867: крутизна генератора gm должна быть не меньше чем в пять раз больше критической gmcrit кварца. При меньшем запасе генератор может запуститься на столе, но не запуститься при другой температуре, напряжении или с другим экземпляром кварца.

Можно ли ставить разные C1 и C2?

Можно: нагрузочная ёмкость считается по той же формуле последовательного соединения. Но критическая крутизна при разных конденсаторах больше, чем при равных, — в (C1 + C2)²/(4·C1·C2) раза; калькулятор это учитывает.

Допущения:

  • Генератор Пирса с кварцем между выводами МК и конденсаторами C1, C2 на землю; паразитная ёмкость Cs — параллельно кварцу, как в формуле AN2867.
  • Кварц — эквивалентная схема Rm, Lm, C1m, C0; уход частоты — по нагрузочному резонансу без учёта Rm.
  • Критическая крутизна — линейная модель при малом ESR; наихудший случай — наибольший ESR и наименьшая gm из паспортов, наибольшая gmcrit по области допуска конденсаторов.
  • Уровень возбуждения — по синусоидальному размаху на входе генератора и наибольшему ESR.

Границы применимости:

  • Паразитная ёмкость Cs задаётся оценкой — фактическую частоту проверяют измерением.
  • Температурный уход, старение и допуск самого кварца не рассчитываются — их учитывает калькулятор делителя частоты по ppm из паспорта.
  • Обертонные кварцы, генераторы с внешним усилителем и кварцевые генераторы в корпусе не рассматриваются.
  • Уровень возбуждения требует измерения на собранной плате; по одному расчёту он не проверяется.
