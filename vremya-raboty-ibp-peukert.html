Время работы ИБП от АКБ с учётом закона Пейкерта

Чем больше ток, тем меньше ампер-часов отдаёт свинцово-кислотная батарея: ёмкость в паспорте указана для долгого, обычно 20-часового разряда. Закон Пейкерта пересчитывает её на ток нагрузки ИБП. Расчёт по энергии без этой поправки делает калькулятор времени работы от аккумулятора — здесь видно, насколько он оптимистичен при большом токе.

Время работы ИБП по закону Пейкерта: как считается

I = P / (U · η),  t = H · (C / (I · H))k,  без поправки: t = C / I
k по двум точкам паспорта: k = lg(H2/H1) / lg(I1/I2),  I1 = C1/H1, I2 = C2/H2
Мощность на элемент для таблицы производителя: P / (η · n),  n = U / 2 В

Закон Пейкерта. В 1897 году Вильгельм Пейкерт получил для свинцово-кислотных аккумуляторов эмпирическое соотношение Ik·t = const: чем больше ток, тем меньше ампер-часов отдаёт батарея. Если ёмкость C указана для H-часового разряда, то есть для тока C/H, то при токе I время работы t = H·(C/(I·H))k. При k = 1 это обычное C/I; чем больше k, тем сильнее падает ёмкость с ростом тока. Батарея 100 А·ч (20-часовой разряд) с k = 1,2 при токе 10 А проработает 8,71 ч — отдаст 87 А·ч вместо 100.

Откуда взять k. Лучше всего — рассчитать по двум ёмкостям из паспорта, как предлагает Victron в руководстве к мониторам батарей: 100 А·ч при 20-часовом разряде и 56 А·ч при 2-часовом дают k ≈ 1,34. Если второй точки нет, Victron по умолчанию берёт 1,25 для свинцово-кислотных, а диапазон настройки монитора — от 1,00 до 1,50. По сводке Википедии (вторичный источник) у AGM обычно 1,05–1,15, у гелевых 1,1–1,25, у заливных 1,2–1,6. Калькулятор принимает k от 1 до 1,6.

Где формула перестаёт работать. Закон Пейкерта выведен для постоянного тока и постоянной температуры (Doerffel и Abu Sharkh, 2006). ИБП разряжает батарею постоянной мощностью: напряжение по мере разряда падает, ток растёт, поэтому расчёт по номинальному напряжению оптимистичен. При токе меньше тока паспортного режима C/H формула даёт ёмкость больше паспортной — это экстраполяция, и калькулятор тогда берёт в оценку C/I. Если k рассчитан по двум точкам, надёжна область между ними; за её пределами результат помечается как экстраполяция.

Таблицы производителя точнее. Для ИБП производители батарей дают таблицы разряда постоянной мощностью: сколько ватт отдаёт элемент за 5, 10, 15, 30 минут до конечного напряжения, например 1,67 или 1,75 В на элемент. У CSB HR1234W — 34,3 Вт на элемент за 15 минут до 1,67 В на элемент при 25 °C. Производители ИБП подбирают батареи по мощности на элемент — нагрузке, делённой на КПД инвертора и число элементов. Калькулятор считает эту величину; время по ней и конечному напряжению вашего ИБП находят в таблице.

Li-ion. Для литий-ионных аккумуляторов закон Пейкерта не применяется: Omar и Van den Bossche (2013) показали, что он описывает их лишь в узком диапазоне токов и температур, а у LiFePO₄ показатель в диапазоне 0–40 °C близок к 1. Victron для литиевых батарей берёт 1,05, если поставщик не указал иное. Поэтому для Li-ion калькулятор даёт только C/I, а допустимый ток и ёмкость задают паспорт и BMS.

Время работы ИБП по закону Пейкерта: пример расчёта

ИБП на 300 Вт с КПД инвертора 85 % работает от батареи 24 В 100 А·ч (C20, k = 1,25). Ток батареи 300 / (24 · 0,85) = 14,71 А — почти втрое больше тока паспортного режима 5 А. Без поправки 100 / 14,71 = 6,8 ч, по Пейкерту 20 · (100 / (14,71 · 20))1,25 = 5,19 ч: батарея отдаст около 76,36 А·ч. Каждый из 12 элементов должен отдавать 300 / (0,85 · 12) = 29,41 Вт — по этой величине время ищут в таблице разряда постоянной мощностью.

Пример из руководства Victron: батарея 100 А·ч при 20-часовом разряде отдаёт 56 А·ч за 2 часа. По этим точкам k = lg 10 / lg 5,6 ≈ 1,337, и при токе 28 А калькулятор даёт ровно 2 ч — точка паспорта воспроизводится.

Частые вопросы

Почему по Пейкерту выходит меньше, чем ёмкость, делённая на ток?

Паспортная ёмкость свинцово-кислотной батареи указана для долгого разряда, обычно 20-часового. При большом токе напряжение раньше падает до конечного, и батарея отдаёт меньше ампер-часов — это и описывает закон Пейкерта.

Где взять показатель Пейкерта?

Рассчитать по двум ёмкостям из паспорта — например, при 20-часовом и 2-часовом разряде; калькулятор делает это в режиме «по второй ёмкости». Если второй точки нет, для свинцово-кислотных Victron по умолчанию берёт 1,25.

Можно ли так считать литиевую батарею ИБП?

Нет: закон Пейкерта выведен для свинцово-кислотных аккумуляторов, а для Li-ion работает лишь в узком диапазоне режимов. У LiFePO₄ показатель близок к 1, поэтому калькулятор даёт C/I, но допустимый ток и ёмкость при нём берут из паспорта батареи и BMS.

Что точнее — формула или таблица производителя?

Таблица разряда постоянной мощностью: она снята для конкретной батареи до конкретного конечного напряжения и уже учитывает, что ток растёт по мере падения напряжения. Формула Пейкерта — приближение, когда таблицы нет.

Допущения:

  • Ток батареи постоянный: I = P / (U·η) при номинальном напряжении.
  • Ёмкость C указана для H-часового разряда до того конечного напряжения, при котором ИБП отключается.
  • Показатель k постоянен во всём диапазоне токов.
  • Для Li-ion поправка на ток не делается: t = C/I.

Границы применимости:

  • Рост тока по мере падения напряжения при разряде постоянной мощностью не учтён — результат оптимистичен.
  • Температура, старение и запас на конец срока службы не учитываются.
  • При токе меньше C/H и вне двух паспортных точек формула Пейкерта — экстраполяция.
  • Точное время — по таблице разряда постоянной мощностью производителя батареи.
