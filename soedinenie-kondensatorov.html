Как считается

Параллельно: C = C₁ + C₂ + … + Cₙ
Последовательно: 1/C = 1/C₁ + 1/C₂ + … + 1/Cₙ

Конденсаторы соединяются «наоборот» по сравнению с резисторами: параллельное соединение увеличивает ёмкость, последовательное — уменьшает. Физически при параллельном соединении складываются площади обкладок, при последовательном растёт суммарное расстояние между ними.

СоединениеЁмкостьРабочее напряжение
ПараллельноеСкладываетсяПо наименьшему
ПоследовательноеУменьшаетсяСкладывается

Пример расчёта

Три конденсатора 100, 200 и 300 мкФ. Параллельно: C = 100 + 200 + 300 = 600 мкФ. Последовательно: 1/C = 1/100 + 1/200 + 1/300, откуда C ≈ 54,55 мкФ — меньше самого маленького номинала.

Частые вопросы

Зачем соединять конденсаторы последовательно, если ёмкость падает?

Ради рабочего напряжения: оно складывается. Два конденсатора на 400 В последовательно выдерживают 800 В. Для равномерного деления напряжения параллельно каждому ставят одинаковые резисторы 100–470 кОм.

Можно ли соединять конденсаторы разной ёмкости последовательно?

Можно, но напряжение распределится неравномерно — большее придётся на меньшую ёмкость. Без выравнивающих резисторов один из конденсаторов может оказаться в перенапряжении.

Складывается ли ток утечки?

При параллельном соединении токи утечки складываются, при последовательном определяются худшим конденсатором — именно он и задаёт распределение напряжения.
