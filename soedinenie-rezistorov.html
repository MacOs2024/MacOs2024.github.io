Параллельное и последовательное соединение резисторов

Выберите тип соединения и введите номиналы. Пустые поля игнорируются, резисторы можно добавлять.

Как считается

Последовательно: R = R1 + R2 + … + Rn
Параллельно: R = 1 / (1/R1 + 1/R2 + … + 1/Rn)

Частный случай для двух параллельных резисторов: R = R1·R2 / (R1 + R2). Для n одинаковых резисторов параллельно: R = R1 / n — так удобно набирать нестандартный номинал или распределять мощность.

Пример расчёта

Три резистора по 10 Ом параллельно: R = 10 / 3 ≈ 3,33 Ом. Те же три последовательно: 30 Ом.

Частые вопросы

Как распределяется мощность между резисторами?

Последовательно больше греется больший номинал (P = I²R, ток общий); параллельно — меньший (P = U²/R, напряжение общее). Суммарная допустимая мощность n одинаковых резисторов в любой схеме — n·P одного.

Можно ли соединять резисторы разных номиналов?

Да, формулы это учитывают. Но параллелить резисторы для деления тока лучше близкими номиналами, иначе почти весь ток пойдёт через меньший.
