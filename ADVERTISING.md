# Реклама VoltCalc: передача Claude

РСЯ, сайт ID 19823062, домен https://macos2024.github.io.
Баннер владельца: R-A-19823062-1. ID блока публичный, это не пароль.

## Изменения и отключение

В generator/common.py:
- YAN_ADS_ENABLED = False полностью убирает загрузчик и баннер при пересборке.
- YAN_AD_BLOCK_ID задаёт реальный ID из кабинета РСЯ.
- yandex_ads() формирует загрузчик и один вызов render.
- @AD_BANNER@ в PAGE определяет место: после карточки калькулятора, перед статьёй.
- .yan-ad и .yan-ad-slot задают отступы и размеры. В печати реклама скрыта.

После изменений выполнить python3 generator/build.py. HTML не менять руками.
Реклама есть только на действующих калькуляторах. Главная, политика,
страница о проекте и отключённый калькулятор рекламы не загружают.
Загрузчик async, расчёт не зависит от рекламы. Повторный расчёт не
обновляет баннер и не вызывает render повторно. В запросе только blockId и
renderTo, значения полей калькулятора код сайта в РСЯ не передаёт.
В privacy.html через генератор добавлено описание рекламной обработки данных.

## Проверка и публикация

npm ci; npm test; python3 generator/build.py; npx playwright test; npm audit.
После коммита повторная генерация должна давать чистый git diff.
Тесты используют заглушку загрузчика или блокируют его; настоящих показов
и кликов при автоматической проверке нет. Заглушка проверяет интеграцию,
но не подтверждает наличие рекламодателя или начисление денег.

Публикация только через PR после CI. После публикации владелец проверяет
реальное отображение на обычном браузере без блокировки рекламы, статистику
видимых показов и вознаграждение в кабинете РСЯ. Не кликать по своей рекламе.
Активный статус сайта показан владельцем на скриншоте; реквизиты, договор,
доступность рекламодателей и выплаты из репозитория проверить нельзя.
