Шум приёмника: коэффициент шума каскадов

В приёмнике с несколькими каскадами шум почти целиком определяют первые: чем больше усиление до каскада, тем меньше его шум влияет на результат. Калькулятор считает коэффициент шума цепочки по формуле Фрииса, показывает вклад каждого каскада, сравнивает порядок «как введено», обратный и лучший, а затем находит порог шума, минимальный обнаружимый сигнал и чувствительность при требуемом SNR. Усиления и коэффициенты шума каскадов вводит пользователь по паспортам. Вычислить потери самого пассивного звена помогает калькулятор аттенюатора, а перевод децибел — калькулятор децибел; найденную чувствительность можно подставить в бюджет радиолинии.

Реклама

Шум каскадной цепочки: как считается

Каскадная формула Фрииса: F = F1 + (F2 − 1)/G1 + (F3 − 1)/(G1·G2) + …,  NF = 10·lg F
Шумовая температура: Te = (F − 1)·T0,  T0 = 290 К,  Te = T1 + T2/G1 + T3/(G1·G2) + …
Пассивный аттенюатор при T0: F = L,  G = 1/L
Порог шума: N = k·T0 + 10·lg B + NF [дБм],  k·T0 = −173,98 дБм/Гц ≈ −174 дБм/Гц
MDS (SNR = 0 дБ) = N;  чувствительность Smin = N + SNRтреб;  с источником Ta: N = 10·lg(k·(Ta + Te)·B / 1 мВт)

Что такое коэффициент шума. Коэффициент шума F — отношение сигнал/шум на входе четырёхполюсника к отношению сигнал/шум на выходе при источнике шума с температурой T0 = 290 К; он показывает, во сколько раз устройство ухудшает это отношение. Строгое определение для любых четырёхполюсников, а не только приёмников с большим усилением, и связь коэффициента шума всего приёмника с коэффициентами его частей дал Фриис (Proc. IRE, июль 1944, «Noise Figures of Radio Receivers»; текст статьи в окружении не открывался, содержание — по аннотации). Эквивалентная шумовая температура Te = (F − 1)·T0 (Pozar, глава 10) не зависит от температуры источника: именно ею удобно складывать шумы разных источников.

Каскадная формула. Шум второго каскада, приведённый ко входу первого, делится на усиление первого, шум третьего — на произведение двух усилений и так далее: F = F1 + (F2 − 1)/G1 + …. Поэтому малошумящий усилитель с большим усилением в начале цепочки «закрывает» шум последующих каскадов, а потери перед ним — нет. Калькулятор показывает вклад каждого каскада как долю избыточного шума F − 1: слагаемое (Fi − 1) делится на общее усиление всех предыдущих. Для усиления в дБ и коэффициента шума в дБ перевод линейный: G = 10G(дБ)/10, F = 10NF(дБ)/10.

Пассивный аттенюатор. Для потерь L (в разах) при физической температуре T0 выходной шум согласованного аттенюатора, нагруженного на источник той же температуры, равен тепловому шуму k·T0·B, а усиление G = 1/L. Тогда F = (шум на выходе)/(G·k·T0·B) = L. Вывод на странице: в выдаче поиска этого положения найти не удалось. Следствие: потери 3 дБ перед усилителем добавляют к коэффициенту шума всей цепочки столько же децибел, сколько составляют сами потери. Если аттенюатор не при T0, F = 1 + (L − 1)·T/T0 — этого калькулятор не делает.

Порядок каскадов. Режим «обратный порядок» и «наилучший из всех перестановок» меняют цепочку, по которой считаются все результаты. Перебор перестановок прямой (до 5! = 120), он не использует эмпирических правил. Для активных каскадов с усилением больше 1 перебор ставит их в порядке возрастания меры шума (F − 1)/(1 − 1/G) — это известный результат теории цепочек; страница его не использует, и в источниках он не подтверждался. Пассивные потери перебор ставит после усилителей: в начале они прибавляются к шуму цепочки почти целиком. На практике порядок ограничен ещё и динамическим диапазоном и фильтрацией, чего калькулятор не учитывает.

MDS и чувствительность. Тепловой шум в полосе B при температуре T0 равен k·T0·B; в дБм это −173,98 + 10·lg B (число округляют до −174 дБм/Гц). Приёмник с коэффициентом шума NF имеет порог шума N = −173,98 + 10·lg B + NF. Минимальный обнаружимый сигнал MDS в этой записи — сигнал, равный шуму (SNR = 0 дБ); чувствительность при заданном SNR на SNR децибел выше. Если задана шумовая температура источника Ta (например, антенна, смотрящая в холодное небо), порог шума считается по k·(Ta + Te)·B. Если ввести уровень сигнала на входе приёмника, например из бюджета радиолинии, калькулятор найдёт отношение сигнал/шум и сравнит его с требуемым.

Чем отличается от соседних страниц. Аттенюатор подбирает резисторы на заданные потери, а здесь потери — число для цепочки. Усиление операционного усилителя считает калькулятор ОУ, перевод децибел — калькулятор децибел.

Шум каскадной цепочки: пример расчёта

Цепочка (значения условные): МШУ с усилением 20 дБ и коэффициентом шума 1,5 дБ, кабель с потерями 3 дБ, усилитель 15 дБ с коэффициентом шума 6 дБ. По формуле Фрииса F = 1,4125 + (1,9953 − 1)/100 + (3,9811 − 1)/(100·0,5012) = 1,482, то есть 1,708 дБ: 85,6 % избыточного шума даёт сам МШУ. Если кабель стоит перед МШУ, F = 1,9953 + (1,4125 − 1)/0,5012 + (3,9811 − 1)/(0,5012·100) = 2,878, то есть 4,59 дБ: потери перед усилителем добавляются к его шуму почти целиком. Перебор всех порядков ставит кабель после усилителя (1-3-2) и даёт 1,592 дБ. Калькулятор показывает все три результата.

При полосе 1 МГц порог шума N = −173,98 + 60 + 1,708 = −112,3 дБм; чувствительность при SNR 10 дБ — −102,3 дБм. Если сигнал на входе приёмника −90 дБм, отношение сигнал/шум 22,27 дБ.

Частые вопросы

Почему малошумящий усилитель ставят в самое начало приёмника?

Шум каждого следующего каскада делится на усиление всех предыдущих. МШУ с усилением 15–20 дБ уменьшает вклад следующих каскадов в 30–100 раз, поэтому коэффициент шума цепочки почти равен коэффициенту шума МШУ. Любые потери перед ним (кабель, фильтр, разъём) прибавляются к коэффициенту шума всей цепочки дБ за дБ.

Чему равен коэффициент шума пассивного аттенюатора?

При температуре T0 — его потерям: у аттенюатора 3 дБ коэффициент шума 3 дБ и усиление −3 дБ. Это следует из теплового шума согласованного резистивного звена; калькулятор подставляет F = L и G = 1/L. Звено при другой температуре шумит иначе, это в расчёт не входит.

Почему вместо −174 дБм/Гц на странице показано −173,98?

Произведение k·T0 при T0 = 290 К и постоянной Больцмана 1,380649·10⁻²³ Дж/К равно 4,004·10⁻²¹ Вт/Гц, то есть −173,98 дБм/Гц; число −174 — округление. Калькулятор использует точное значение, поэтому результаты могут отличаться от «округлённых» на 0,02 дБ.

Что считается минимальным обнаружимым сигналом?

Здесь MDS — уровень сигнала на входе приёмника, равный его собственному шуму (SNR = 0 дБ). Определения у изготовителей различаются (например, SNR 3 дБ), поэтому для реального приёма вводят требуемое SNR и получают чувствительность Smin = MDS + SNR. Значение SNR берут из паспорта вида модуляции.

Допущения:

  • Каскады линейны, согласованы, шум каждого — тепловой; коэффициент шума каждого активного каскада и его усиление заданы пользователем по паспорту.
  • Пассивные звенья находятся при температуре T0 = 290 К: F = L, G = 1/L.
  • Полоса шума B — эквивалентная шумовая полоса приёмника; постоянная Больцмана k = 1,380649·10⁻²³ Дж/К, T0 = 290 К.
  • MDS — уровень сигнала, равный шуму приёмника (SNR = 0 дБ).

Границы применимости:

  • Нелинейность, динамический диапазон, зеркальный канал, фазовый шум и помехи не рассматриваются.
  • Пассивное звено при температуре, отличной от 290 К, и рассогласование между каскадами не учитываются.
  • Коэффициент шума зависит от частоты, режима и сопротивления источника; страница использует единственное число на каскад.
