Г-образная LC-цепь согласования

Две активные нагрузки с разными сопротивлениями можно согласовать на одной частоте двумя реактивными элементами в виде буквы Г. Калькулятор находит L и C для обоих вариантов — ФНЧ (последовательная катушка, параллельный конденсатор) и ФВЧ (последовательный конденсатор, параллельная катушка) — добротность Q, полосу по уровню −3 дБ и потери из-за конечной добротности катушки. Что получится после согласования, показывает калькулятор КСВ; сопротивление линии по размерам — калькулятор волнового сопротивления.

R1 должно быть больше R2: цепь из двух элементов только понижает или повышает сопротивление в одном направлении
Q = X / r, по паспорту катушки или измерению; пусто — потери в катушке не считаются
Полная ширина полосы сигнала с центром на f; пусто — достаточность полосы не проверяется

Реклама

Г-образная LC-цепь согласования: как считается

Q = √(R1/R2 − 1),  Xпосл = Q·R2,  Xпарал = R1/Q,  ω = 2πf
ФНЧ: L = Q·R2/ω (последовательная),  C = Q/(ω·R1) (параллельная)
ФВЧ: C = 1/(ω·Q·R2) (последовательная),  L = R1/(ω·Q) (параллельная)
Проверка: Zвх = R (подстановкой L и C в комплексное сопротивление)
Полоса: приближённо 2f/Q при Q ≫ 1 (нагруженная добротность Q/2); точно — по уровню −3 дБ передачи мощности

Откуда формулы. Параллельный элемент всегда стоит на стороне большего сопротивления R1, последовательный — на стороне меньшего R2. Пусть источник R1 и параллельная проводимость jB, затем последовательное сопротивление jX и нагрузка R2. Со стороны источника проводимость цепи равна jB + 1/(R2 + jX), и для согласования она должна быть равна 1/R1. Вещественная часть: R2/(R2² + X²) = 1/R1, откуда X² = R2·(R1 − R2) = (Q·R2)², Q = √(R1/R2 − 1). Мнимая часть: B = X/(R1·R2) = Q/R1, то есть реактивное сопротивление параллельного элемента R1/Q. Для схемы, где источник R2, а нагрузка R1, получаются те же значения (проверено подстановкой). В главе 5 учебника Позара (Microwave Engineering, раздел 5.1 о согласовании сосредоточенными элементами, «L-цепи») по оглавлению издателя в выдаче разбираются два решения для произвольной нагрузки — аналитически и на диаграмме Смита; текст книги не использовался, формулы выведены заново. Q = √(R1/R2 − 1) и то, что Q и полоса согласования при двух элементах фиксированы, видны и в учебнике Steer (LibreTexts, раздел о L-цепи) в выдаче поиска. Ссылку на ARRL Handbook подтвердить не удалось, и она не ставится.

Два варианта. Реактивные сопротивления одинаковые по модулю в обоих вариантах, но знак разный. ФНЧ: последовательная катушка с реактивным сопротивлением +Q·R2 и параллельный конденсатор с −R1/Q. ФВЧ: последовательный конденсатор −Q·R2 и параллельная катушка +R1/Q. Низкочастотный вариант пропускает постоянный ток и подавляет гармоники, высокочастотный разделяет цепи по постоянному току и подавляет низкие частоты. Оба варианта согласуют сопротивления на частоте f одинаково, различается только поведение вне неё.

Полоса. Q звена нельзя выбрать: Q = √(R1/R2 − 1) определяется только отношением сопротивлений. Поэтому полоса фиксирована. Практическое правило «полоса равна f/Q» для передачи мощности между источником и нагрузкой неточно: контур нагружен и источником, и нагрузкой, нагруженная добротность равна Q/2, и при Q ≫ 1 ширина полосы по уровню −3 дБ близка к 2f/Q. Для Q = 3 точный расчёт даёт для ФНЧ 3,817…9,134 МГц на частоте 7 МГц — ширину 5,318 МГц, а f/Q = 2,333 МГц, 2f/Q = 4,667 МГц; полоса несимметрична. Поэтому страница показывает границы по −3 дБ, найденные поиском делением отрезка по частоте, а правила f/Q и 2f/Q — только для сравнения. Если полоса получается слишком узкой, цепь составляют из нескольких Г-звеньев с промежуточными сопротивлениями; если слишком широкой — используют П- или Т-цепь с большей Q.

Добротность катушки. Катушка с добротностью Qк = X/r имеет последовательное сопротивление потерь r = X/Qк на частоте f. У ФНЧ катушка стоит в последовательной ветви, у ФВЧ — в параллельной. Потери считаются точным расчётом передачи мощности цепью с этой катушкой при тех же L и C. Для грубой оценки при Qк ≫ Q потери близки к 4,34·Q/Qк дБ (в проверенных случаях точное значение на 0,3–2,5 % меньше), но страница показывает не оценку, а расчёт.

Чем отличается от соседних страниц. Здесь согласуются два активных сопротивления на одной частоте. Что получится, если оставить рассогласованную нагрузку, — калькулятор КСВ и коэффициента отражения. Резонанс одного LC-контура — калькулятор резонансной частоты, фильтр из тех же элементов — калькулятор LC-фильтра. Сопротивление линии по размерам даёт калькулятор волнового сопротивления.

Г-образная LC-цепь согласования: пример расчёта

Усилитель с выходным сопротивлением 50 Ом нужно согласовать с нагрузкой 5 Ом на частоте 7 МГц (источник — большее сопротивление). Q = √(50/5 − 1) = 3. ФНЧ: последовательная катушка L = 3·5/(2π·7·10⁶) = 341 нГн (15 Ом) и параллельный конденсатор C = 3/(2π·7·10⁶·50) = 1,364 нФ (16,67 Ом). ФВЧ: последовательный конденсатор 1,516 нФ и параллельная катушка 378,9 нГн. Подстановкой в уравнение: Zвх = 50 + j0 Ом.

Полоса по −3 дБ у ФНЧ — от 3,817 до 9,134 МГц, у ФВЧ — от 5,364 до 12,84 МГц. Если катушка имеет добротность 50 на 7 МГц, потери у ФНЧ — 0,2567 дБ, у ФВЧ — 0,2566 дБ. Второй пример: 200 Ом и 50 Ом на 14,2 МГц. Q = 1,732, ФНЧ: L = 970,6 нГн и C = 97,06 пФ, ФВЧ: C = 129,4 пФ и L = 1,294 мкГн.

Частые вопросы

Почему нельзя выбрать добротность и полосу?

У цепи из двух элементов один параметр — Q — полностью определяется отношением сопротивлений: Q = √(R1/R2 − 1). Больше степеней свободы даёт цепь из трёх элементов (П- или Т-цепь): там Q задаётся отдельно и может быть выше, чем у Г-звена.

Какой вариант выбрать — ФНЧ или ФВЧ?

Оба согласуют сопротивления на частоте f. ФНЧ подавляет гармоники и пропускает постоянный ток; ФВЧ разделяет цепи по постоянному току и подавляет низкие частоты. Выбирают по тому, что нужно вне частоты согласования, и по тому, какие значения L и C легче реализовать.

Меняет ли расчёт то, что больше — сопротивление источника или нагрузки?

Значения L и C те же, но меняется схема: параллельный элемент стоит на стороне большего сопротивления. Передача мощности от направления не зависит, поэтому потери и полоса тоже не меняются.

Почему полоса в расчёте не равна f/Q?

Правило f/Q годится для одиночного контура с заданной нагруженной добротностью. В согласующем звене нагруженная добротность равна Q/2, поэтому при Q ≫ 1 полоса по −3 дБ ближе к 2f/Q. Страница считает точные границы по передаче мощности.

Допущения:

  • R1 и R2 — чисто активные, постоянные на частоте согласования; элементы идеальные, кроме учтённой по желанию добротности катушки.
  • Согласование точное на одной частоте f; вне её передача определяется самой цепью (полоса по −3 дБ считается точным расчётом цепи).
  • Катушка с добротностью Q моделируется последовательным сопротивлением r = X / Q на частоте f; конденсатор идеальный.

Границы применимости:

  • Паразитные параметры элементов (собственная ёмкость катушки, индуктивность выводов конденсатора) и зависимость R1, R2 от частоты не учитываются; настройку проверяют измерением.
  • Согласуются только активные сопротивления; комплексную нагрузку сначала компенсируют добавочным элементом.
  • Требуемая полоса проверяется по уровню −3 дБ: равномерность в полосе и фазовые искажения не оцениваются.
  • Правило «BW ≈ f/Q» источником не подтверждено (ARRL Handbook в выдаче не найден): страница показывает точный расчёт по −3 дБ и оба правила, f/Q и 2f/Q, только для сравнения.
